## 🌟 Advantages of the Web Edition

1. **Native 60 FPS Performance:** Runs directly in Google Chrome / Microsoft Edge using **MediaPipe Tasks Vision WebAssembly (WASM)** with GPU acceleration.
2. **Zero Client Installation:** No complex C++ compilers or Python libraries needed for judges or end-users.
3. **Modern Cyberpunk UI:** Glassmorphism UI styled with Tailwind CSS, glowing neon HUD overlays, and responsive animations.
4. **Interactive 2-Way Assistive Communicator:** Features Web Speech API for real-time Text-to-Speech (TTS) and voice recognition.
5. **Addictive Edutainment Suite:** Includes *SignBeat Arcade* (rhythm game), *BIM Blitz* (60s speed charades), and *Ghost Skeleton Mirror* (posture alignment).

---

## 🚀 How to Run

### Quick Start:
From your terminal / PowerShell:
```powershell
cd C:\Users\USER\.gemini\antigravity\scratch\isyarathero-web
python server.py
```
This automatically launches your browser and navigates to `http://localhost:8080`.

## ⌨️ Controls & Shortcuts

* **`[1]`**: Penterjemah 2-Hala (Assistive 2-Way Communicator)
* **`[2]`**: SignBeat Arcade (Rhythm Game)
* **`[3]`**: BIM Blitz (60s Speed Charades)
* **`[4]`**: Ghost Skeleton Mirror (Guided Training)
* **`[M]`**: Laman Utama (Home Menu)
* **`[SPACE]`**: Baca Keseluruhan Ayat (dalam mod Penterjemah)
* **`[C]`**: Padam Ayat (dalam mod Penterjemah)
* **`[R]`**: Main Semula (dalam mod Blitz)
* **`[N]` / `[P]`**: Isyarat Seterusnya / Terdahulu (dalam mod Mirror)
